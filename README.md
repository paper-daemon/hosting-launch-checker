# Hosting Launch Checker

公開前後のWebサイト確認項目を整理する静的チェックリスト。対象サイトへ自動アクセスしてHTTP状態を診断するツールではありません。アフィリエイト欄は承認済み案件のみ有効化する設計。

- [現在のscopeと非対応範囲](docs/scope-contract.md)

## 現在有効な広告候補

- ドメイン / サーバー: お名前.com

チェックリスト機能自体は広告なしで利用でき、広告枠は確認項目の内容には影響しません。

## Affiliate policy
The tool stays useful without affiliate links. Only approved programs may be enabled, with clear disclosure. Unapproved services use normal official links or no link.

## Current monetization
承認済みプログラムだけを広告表記付きで有効化します。チェックリスト本体は広告リンクなしでも利用できます。
